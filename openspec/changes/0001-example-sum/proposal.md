# 變更提案 0001：sum() 加總函式

狀態：`example`（示範用，可刪）

## 為什麼
需要一個把數字陣列加總的純函式，作為 TDD 流程的最小示範。

## 要做什麼
提供 `sum(numbers: number[]): number`。

## 驗收條件（→ 每條對應一個測試）
- [x] 空陣列回傳 `0`
- [x] `[1,2,3,4]` 回傳 `10`
- [ ] （下一循環）含 `NaN` 時忽略 `NaN`，例：`[1, NaN, 2]` → `3`

## 影響的 spec
- 新增 `openspec/specs/sum.md`（實作完成、測試全綠後再寫入 canonical 規格）
